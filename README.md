# 📌 Portfolio Website

A modern, interactive portfolio built with **Next.js App Router** and **3D animations** to showcase my projects, skills, and journey.  
This project highlights my academic achievements, technical expertise, and professional branding.

---

## ✨ What’s Inside
- Home page with interactive 3D animations and particle background  
- About page describing my journey and skills  
- Projects showcase:
  - Smart Medical AI Assistant  
  - Local Market Place  
  - Student Complaint Management System  
  - Portfolio (this site itself)  
- Contact page with functional form (Resend API + Google Sheets integration)  
- Responsive design with SEO optimization  

---

## 🛠 Tech Used
- **Framework:** Next.js 16 (App Router)  
- **Language:** TypeScript  
- **Styling:** TailwindCSS  
- **Animations:** Three.js, React Three Fiber, Particle System  
- **Backend APIs:** Resend (emails), Google Sheets (data storage)  
- **Deployment:** Vercel  

---

## 🌐 Deployment
This portfolio is deployed on **Vercel**, which provides seamless hosting for Next.js projects.
